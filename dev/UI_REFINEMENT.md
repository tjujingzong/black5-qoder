# 挤黑五 UI 优化 · 2026-11-09

方向：夜间绿呢牌桌。中性深色界面承托绿色牌桌、米白牌面与少量琥珀色回合提示，以黑桃 5 作为统一标记。

审计发现：首页在桌面上留白过多；牌桌与回合提示有重复发光、跳动和循环动画；控制栏混用 emoji；部分手机文字小于 11px；手牌不支持键盘选择。

## 本次调整

1. **间距**：统一控件、玩家列表与面板的间距和尺寸，按 4px 基准安排布局
2. **颜色**：收敛界面底色与边框，颜色集中在实际牌桌、牌面、回合与结算状态
3. **图标**：用本地 SVG 线性图标替换 emoji，使用统一的 18px 尺寸和 1.5px 描边
4. **文案**：首页说明秘密队友玩法，简化进入房间、邀请与独庄提示
5. **字体**：正文采用系统中文字体，首页标题用宋体，积分与房间号采用等宽数字
6. **布局**：桌面首页使用介绍与入局表单双栏；手机按阅读顺序堆叠，房间、聊天与牌局适配窄屏
7. **细节**：手牌使用原生按钮，支持键盘选择与选中状态；保留焦点和横向滚动；缩放窗口时重新安排手牌
8. **视觉**：首页用 HTML/CSS 绘制黑桃 5 牌面，牌桌增加内侧边界，不引入图片生成或额外运行时依赖
9. **动效**：移除循环发光与跳动；保留倒计时、一次回合提醒和互动反馈，并支持减少动态效果偏好

## 验证

使用本地开发服务器和 Chromium 验证双浏览器会话，共通过 35 项检查：创建房间、邀请加入、准备、六人开局、键盘选牌、提示、出牌、聊天、快捷语音标记、互动菜单、音乐与音效开关、完整一局结算及下一局。使用模拟麦克风验证开关图标与状态。另行确认叠放牌面花色可见、选牌保留横向滚动位置。检查 1440px、768px、390px、320px 宽度，无页面横向溢出或 JavaScript 运行错误。JavaScript 语法检查与 `git diff --check` 通过。

`npm run check` 依赖 Deno，本次环境没有 Deno，因此未完成该项。语音音频传输需要部署端接口，本地验证覆盖图标与状态显示。
