# Avatar attribution

The PNG files in this directory were generated with DiceBear using the
**Adventurer** avatar style by Lisa Wischofsky.

- Generator: https://www.dicebear.com/
- Style: https://www.dicebear.com/styles/adventurer/
- License: Creative Commons Attribution 4.0 International
- License URL: https://creativecommons.org/licenses/by/4.0/

The generated PNG files are stored locally so the game does not depend on the
DiceBear API at runtime.

`public/favicon.ico` reuses the `tiger.png` avatar from this attributed set.
